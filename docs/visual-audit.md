# Visual audit

Compared with `design/reference` (from `cura_design_reference.zip`, 28 screens). A card that holds a score, count, range, trend, percentage, or status gets one hero visual and one short caption. Forms, legal prose, and visit notes stay text.

Missing readings stay empty (ghost chart or an em dash). A zero is not drawn as a real score.
